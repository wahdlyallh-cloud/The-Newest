# حياة AI (Hayat AI) 🌿✨

منصة ذكية متكاملة لإدارة الحياة، تدوين اليوميات، متابعة العادات، والمستشار النفسي الذكي المدعومة بنموذج الذكاء الاصطناعي (Google Gemini 2.5 Flash).

---

## 🌟 أبرز مميزات التطبيق

1. **تدوين اليوميات والخواطر الذكية:**
   - كتابة خواطر مع خيارات تنسيق كاملة، تغيير الخطوط والألوان.
   - كاتب الملاحظات الذكي (AI Note Writer) لتوليد أفكار ونصوص ملهمة.
   - دفتر الامتنان اليومي وشجرة النمو النفسي.

2. **التفريغ النصي للتسجيلات الصوتية:**
   - دعم رفع وتفريغ المقاطع الصوتية بجميع الصيغ (`.mp3`, `.m4a`, `.wav`, `.aac`, `.ogg`, إلخ).
   - تحويل الملاحظات والتسجيلات إلى نص عربي دقيق باستخدام نموذج Gemini 2.5 Flash.

3. **المستشار والمساعد النفسي الذكي:**
   - شات تفاعلي ومستشار ذكي لتقديم نصائح وتوصيات مخصصة، تحليل الحالة المزاجية، وتمارين العلاج المعرفي السلوكي (CBT).

4. **تتبع العادات والصحة اليومية:**
   - مصفوفة العادات، تتبع النوم والمزاج والأنشطة والطقس.
   - تحليلات ورسوم بيانية لربط العادات بالصحة النفسية والمزاج.
   - تقارير علاجية وتصدير تقارير PDF شهرية.

5. **الأمان والنسخ الاحتياطي:**
   - قفل اليوميات برقم سري (PIN).
   - حفظ البيانات محلياً مع إمكانية المزامنة والنسخ الاحتياطي عبر البريد الإلكتروني أو الملفات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** React 18, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Framer Motion, Recharts, jsPDF.
- **الخلفية (Backend):** Node.js, Express.js (Full-stack architecture).
- **الذكاء الاصطناعي (AI):** Google GenAI SDK (`@google/genai`) مع نموذج `gemini-2.5-flash`.
- **أداة البناء (Bundler):** Vite + esbuild.

## 🚀 طريقة التثبيت والتشغيل المحلي

### 1. استคลون المشروع وتثبيت الحزم
```bash
git clone https://github.com/YOUR_USERNAME/hayat-ai.git
cd hayat-ai
npm install
```

### 2. إعداد متغيرات البيئة (Environment Variables)
قم بإنشاء ملف `.env` في المجلد الرئيسي واستنسخ محتوى `.env.example`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. تشغيل خادم التطوير (Development)
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 4. البناء والتشغيل للإنتاج (Production)
```bash
npm run build
npm run start
```

## 📤 كيفية رفع المشروع على GitHub

اتبع الخطوات التالية لرفع المشروع على حسابك في GitHub:

1. **قم بإنشاء مستودع جديد (New Repository)** على GitHub باسم `hayat-ai` (لا تقم بإضافة README أو .gitignore من GitHub لأنها موجودة بالفعل بالمشروع).

2. **افتح التيرمينال (Terminal) في مجلد المشروع واكتب الأوامر التالية:**

```bash
# 1. تهيئة المستودع المحلي
git init

# 2. إضافة جميع الملفات
git add .

# 3. حفظ التغييرات (Commit)
git commit -m "Initial commit: Hayat AI platform"

# 4. تغيير اسم الفرع الرئيسي إلى main
git branch -M main

# 5. ربط المستودع المحلي بمستودع GitHub (استبدل YOUR_USERNAME باسم حسابك)
git remote add origin https://github.com/YOUR_USERNAME/hayat-ai.git

# 6. رفع الملفات إلى GitHub
git push -u origin main
```
